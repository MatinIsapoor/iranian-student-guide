# راهنمای دانشجویان ایرانی خارج از کشور

یک اپلیکیشن وب ساده با Flask که راهنماهای زندگی دانشجویی (خرید، مسکن، مدارک و...) رو برای دانشجویان ایرانی مقیم کشورهای مختلف ارائه می‌ده.

## وضعیت فعلی
- ✅ راهنمای خرید و زندگی روزمره (آلمان، کانادا، آمریکا)
- ⬜ راهنمای مسکن
- ⬜ راهنمای کارت دانشجویی و مدارک
- ⬜ اضافه کردن کشورهای بیشتر

## اجرای پروژه به صورت محلی

```bash
# ساخت محیط مجازی (اختیاری ولی پیشنهادی)
python -m venv venv
source venv/bin/activate   # ویندوز: venv\Scripts\activate

# نصب وابستگی‌ها
pip install -r requirements.txt

# اجرای برنامه
python app.py
```

بعد از اجرا، به آدرس `http://127.0.0.1:5000` برو.

## ساختار پروژه

```
iran-student-guide/
├── app.py              # فایل اصلی Flask
├── data/
│   └── guides.json     # محتوای راهنماها (اضافه کردن کشور/مطلب جدید از همینجا)
├── templates/           # قالب‌های HTML
├── static/
│   └── style.css
├── requirements.txt
└── README.md
```

## چطور یه راهنمای جدید اضافه کنم؟
کافیه فایل `data/guides.json` رو باز کنی و یه کشور یا آیتم جدید داخل ساختار موجود اضافه کنی. نیازی به تغییر کد نیست.
