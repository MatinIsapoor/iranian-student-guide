# 🇮🇷 Iranian Student Guide

A Flask-based web application that helps Iranian students find practical information about studying and living abroad.

## 🌐 Live Demo

[Visit the website](https://iranian-student-guide.onrender.com)

## ✨ Features

- 🌍 Country-based guides
- 📚 Categorized information
- 🏠 Housing information
- 🛍️ Shopping information
- 🔗 Useful external resources
- 📱 Responsive web interface

## 🛠️ Tech Stack

- 🐍 Python
- 🌐 Flask
- 🎨 HTML & CSS
- 📄 JSON

🎯 Project Goal

The goal of this project is to provide Iranian students with useful and practical information about studying and living abroad in one accessible place.

The project aims to make important information easier to find and navigate.
